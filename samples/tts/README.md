# TTS listening sample files

These are generated outputs selected by case ID, plus the shared FLEURS voice
reference needed to interpret the cloning examples. No listener scores or
preferences are collected in this directory.

See [`docs/tts-listening.md`](../../docs/tts-listening.md) for prompts and
links. Model revisions and output hashes are recorded under `results/tts/`.

The FLEURS reference is CC BY 4.0 and comes from the `ro_ro` test split
published by Google through Hugging Face. Generated outputs keep any
restrictions imposed by their model licences; see `docs/tts-models.md`.
